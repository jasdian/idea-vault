What is the cheapest, fastest test that could disprove this idea?

First name the ONE load-bearing assumption the idea cannot survive losing — the belief that, if false, kills it. Then design the smallest experiment that could show it is false.

Answer in this shape:
- **Load-bearing assumption:** one sentence.
- **Disproof test:** what to do, concretely — who, what, where.
- **Cost and time:** money and calendar time; aim for under a day and close to zero cost.
- **Kill signal:** the observable result that means the idea is dead, stated before the test runs.
- **Survive signal:** the result that means the assumption holds — and what it still would not prove.
- **Cheaper still:** an even rougher version, if one exists.

Prefer tests against reality (ask a real buyer, try to pre-sell, search for the thing already existing, put up a fake door) over more analysis. If the discussion already ran a test, build on its result instead of repeating it.
